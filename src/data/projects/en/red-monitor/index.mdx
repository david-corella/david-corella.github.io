A C# (.NET 8) console application that detects the machine's network interfaces and shows, for each
one, its description, name, type, operational status, MAC address, and IP addresses (IPv4/IPv6). The
project let me work with the `System.Net.NetworkInformation` API to inspect the Windows network stack
from code.
