Desarrollé un sistema de gestión escolar modular en C# con Windows Forms en Visual Studio 2022 y una
base de datos relacional. El proyecto fortaleció mis bases en el desarrollo de escritorio con el
ecosistema .NET y en cómo conectar la persistencia con una interfaz visual funcional.
