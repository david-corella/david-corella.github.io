Aplicación de consola en C# (.NET 8) que detecta las interfaces de red del equipo y muestra, para
cada una, su descripción, nombre, tipo, estado de operación, dirección MAC y direcciones IP
(IPv4/IPv6). El proyecto me permitió trabajar con la API `System.Net.NetworkInformation` para
inspeccionar la pila de red de Windows desde código.
