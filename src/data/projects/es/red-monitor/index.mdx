Aplicación de escritorio cuyo propósito es capturar el estado actual de todas las interfaces de red
del equipo y guardar ese registro de forma segura en SQL Server. El desarrollo reforzó mis criterios
para estructurar software robusto, tolerante a fallos y responsivo.
